# /day-start

오늘 작업을 시작한다. **읽기만 한다. 파일을 고치거나 커밋하지 않는다.**

## 1. 읽을 것

1. `docs/roadmap.md` — "현재 위치" 체크박스, 날짜별 계획, 마감일, "변경 기록" 마지막 몇 줄.
   파일이 없으면 "roadmap.md가 아직 없다"고 맨 위에 알리고, 아래 2~3만으로 진행한다.
2. git 기록:
   - `git log --since="7 days ago" --stat --format='%h %ad %s' --date=short`
   - `git status --short` (커밋 안 한 작업이 남아 있는지)
3. `README.md` 진행 상황 표와 `docs/reports/`의 마지막 `step-NN.md` (미통과·미측정 조건).
4. `docs/decisions.md`, `docs/study/`(단계 노트, `daily/`)의 최근 파일 (무엇까지 정리됐는지만 확인).
5. 오늘 날짜와 요일: `date '+%Y-%m-%d %a'`. 주말이면 "주말 휴식 원칙"을 먼저 알리고, 그래도 할지 묻는다.

## 2. 출력 (이 순서, 한국어, 짧게)

### 지난번에 멈춘 지점
- 마지막 커밋과 커밋 안 된 변경, 마지막으로 끝낸 실습 단계와 다음 단계.

### 남은 질문
- 답을 기다리는 것(강사 확인, 팀 결정, 내 승인 대기)을 한 줄씩. 언제까지 필요한지 같이 쓴다.
- 없으면 "없음".

### 오늘 할 일 (3개 이내)
- 하루 **5시간** 기준. 각 항목에 예상 시간을 붙이고 합이 5시간을 넘지 않게 한다.
- 순서: 막힌 것을 푸는 일 → 모델 다운로드·학습처럼 오래 걸리는 일을 일찍 시작 → 나머지.
- 같은 보드 팀원과 GPU·카메라를 겹쳐 쓰지 않도록, 보드를 오래 쓰는 일은 시간대를 적는다.
- 각 항목: `무엇 — 왜 오늘 — 예상 시간 — 끝났다고 볼 기준`.

### 오늘 어디까지 갈 수 있나
- roadmap의 날짜별 계획과 비교해 "계획대로 / N일 밀림 / 앞섬"을 말한다.
- 밀렸으면 줄일 후보(5단계 음성 생략, 갈래 하나만 선택)를 추천안 1개 + 이유 1줄 + 버리는 것 1줄로 쓴다.
  roadmap은 고치지 않는다(고치는 것은 `/day-end`).

### 내가 직접 해야 하는 것 (있을 때만, 3개 이내)
- sudo, 카메라 연결, push, 팀 알림, 강사 질문처럼 Claude가 대신 못 하는 행동만.
