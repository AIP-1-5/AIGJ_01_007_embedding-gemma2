## 실제로 겪은 문제 → 원인 → 해결
- yoloe `No module named 'clip'` → YOLOE 텍스트 인코더가 CLIP 패키지 요구, 자동 설치는 꺼 둠 → 아래.
- `pip install git+…/CLIP.git`이 `setuptools>=70`을 못 찾음, 맥도 `No route to host` → 교육장 네트워크가 pypi.org를 막음(github.com, huggingface.co는 됨) → GitHub에서 받아 torch 고정 오프라인 설치. 외부 코드 설치는 권한 검사에서 막혀 사용자가 직접 승인했다.
- 9-5 1차 요약 2개 → 카메라가 책상 위 1m라 사용자가 화면을 안 떠남 → 카메라 재배치. 2차도 시도 12회에 요약 7개.
- 1차 동작 녹화에서 엉덩이 0%, wave에 손 든 프레임 0 → 카메라가 내려다봄 → 재녹화.
- `action.pt` 정확도 0.358 → 재학습 로그로 확인: 검증 최고 epoch 0, 학습 손실 0.006 → 라벨당 녹화 1개라 암기한 것으로 추정(원문은 최소 2개). 각도 차이 가설은 정면 점수 분포로 기각.
- `media/` 삭제가 권한 검사에서 막힘 → 되돌릴 수 없는 삭제라 사용자가 직접 실행하기로.
- 앱 재시작 대기가 안 끝남 → `pgrep -f`가 내 셸 명령 자체와 일치 → 시간 제한 대기로 바꿈.
- 오프라인 검색 정답 목록에서 세탁기 화면 2개 누락 → `microwave` 라벨 크롭만 보고 정답을 정함 → 결과를 보고 정답을 바꾸지 않고 10/12로 기록, 사정을 보고서에 남김.
