### 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 렌즈 보정 RMS 1.4~3.5px | C920 자동초점 | `v4l2-ctl`로 끄고 다시 찍음 |
| 위치 보정 3회 | 1차 책상 위, 2차 공간 좁고 카메라 낮음 | 방 전체 기준점, 원점 바닥 |
| 첫 계산 172px | 기준점 3·4번 라벨 바뀜 | json 좌표 교환 |
| 작은 상자를 cam1이 못 찾음 | 16px 미만 후보 제외 | 큰 갈색 상자로 교체 |
| 이동 타겟 10~14m 튐 | 상자 높이가 카메라 높이와 비슷 | 낮게 들기 |
| 상자가 8m 밖·바닥 아래 | 보정 뒤 cam0이 약 6° 돌아감 | 보정 때 화면과 비교해 손으로 복원 (0~2px) |

**한계:** 카메라 높이 1.35~1.41m(권장 2.2~2.5m), 시선 각도 23°(권장 60~90°). 한 카메라 추정이 크게 틀리고 앞뒤 오차가 커진다.

## 배운 것

1. **보정값은 설치 상태의 스냅샷이다.** 카메라가 6° 돌아가자 같은 코드가 상자를 바닥 아래 47cm로 계산했다. 보정 직후 화면을 남겨 두고 비교해야 한다.
2. **지표 하나로 판단하지 않는다.** 재투영 오차는 기준을 넘었지만(3.78px) 독립 검증점은 3cm였다. 3단계 1·2위 차이 0.006처럼 "통과"여도 여유를 같이 본다.
3. **가정에 기대는 폴백은 조용히 틀린다.** 발목=바닥, 어깨=1.2m 가정은 배치가 나쁘면 1m 넘게 빗나간다. 9단계의 확신 기준 폴백처럼 "추정"임을 드러내야 한다.
4. **경계 판정에는 여유(히스테리시스)를, 움직이는 것에는 시간(TTC)을.** 1.0m에 20초 서 있어도 알람 1번, 다가오는 물체는 최대 3초 먼저 경고.
