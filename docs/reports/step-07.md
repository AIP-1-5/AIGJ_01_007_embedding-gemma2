## 관찰

- 맥 기준 평가(float32 MPS)는 acc@1 **0.833**, 보드(bfloat16 CUDA)는 **0.817**. 차이는 질의 1개("목이 칼칼하고 공기가 건조해요", 보드에서 0.001 차로 오답). 같은 모델·데이터라도 dtype에 따라 경계의 질의가 뒤집힌다(3단계 dtype 관찰과 같은 현상).
- 학습 후 보드 bf16 점수는 맥 float32 학습 후 점수와 같았다(0.867/0.95/1.0/0.94).
- epoch별(맥) acc@1: 학습 전 0.833 → 1: 0.867 → 2: 0.867 → 3: 0.867. ndcg@10: 0.92 → 0.933 → 0.941 → 0.94. 1 epoch 뒤로는 거의 변화 없음.
- 차원별 acc@1 (보드): 768 0.817 → 0.867, **256 0.767 → 0.833, 128 0.617 → 0.750**. MatryoshkaLoss로 잘린 차원의 손실이 줄었다.
- 1위 오답: 11개 → 8개. 새로 틀린 질의 1개("점심 먹고 왔더니 불이 다 꺼져 있어요" → 조도 문서, 차이 0.032).
- 한 문서가 1위를 가져간 최대 횟수(정상 3): 7 → 5. "재실 0명 → 냉난방 끄기" 문서가 여전히 냉난방·에이전트 질의를 끌어온다.
- **점수 척도 변화**: 3단계 질의 1 최고 점수 0.717 → 0.264, 질의 2 0.725 → 0.492. 1-2위 차이는 질의 2에서 0.069 → 0.342로 커졌다. 절대 점수 임계값(예: "0.6 이상이면 일치")은 미세 조정 모델에서 다시 정해야 한다.
- 3단계 질의 1(CO2 vs 조도)은 원래도 차이 0.006이었다. 학습 데이터에 "조도"와 "졸림·집중" 문장이 같이 있지 않은데도 경계가 반대쪽으로 넘어갔다.

## 한계

- 학습·평가 데이터를 같은 작성자(Claude)가 같은 날 썼다. 문체·표현 습관이 겹쳐 학습 효과가 실제 교육생 질의보다 좋게 나왔을 수 있다. 실제 질의 로그나 다른 사람이 쓴 평가 세트로 다시 재야 한다.
- 평가 60쌍에서 질의 1개 = accuracy 0.017. 0.817 → 0.867은 질의 3개 차이다. 반복 학습(시드)별 분산은 미측정.
- 미세 조정 모델은 텍스트 전용이다(비전·오디오 인코더 없음). 8단계부터는 원본 모델을 쓴다(원문과 같음).
